A shape is only 'un-bypassable' relative to a stated tolerance.

Loosen it and a zigzag is one straight line.

==============================================================================
THE LIMIT OF THIS TEST
==============================================================================

  The fitter searches a hypothesis class: polynomial turn/step
  sequences up to degree 3, and periodic sequences up to period 12.

  'varying curvature (smooth)' scores VALID above -- but it was
  generated by  right(6 + 4*sin(2*pi*i/60)); forward(9), which is a
  closed form with three constants. The fitter missed it because a
  sinusoid is not in the hypothesis class.

  So the verdict is 'no cheap program FOUND', never 'no cheap program
  EXISTS'. Widen the hypothesis class and more items die. This test
  can only ever return a lower bound on degeneracy.

  Consequence for the benchmark: item validity rests on an assumption
  that cannot be proved, only failed to be disproved.
